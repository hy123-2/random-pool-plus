# 随机池＋ / Random Pool+

Folia 自带的「每首歌随机歌词动画」只能在内建样式里挑。它的候选集是宿主代码里写死的 17 个内建 id
（`new Set(Kn)` 过滤 `listModes()` 的结果），所以由模组注册的歌词样式（`mod:` 前缀）永远进不了那个池，
设置页也永远显示「已选 17/17」。

本模组绕开这个白名单：直接用 `folium.visualizer.listModes()` 拿**全部已注册样式**（内建 + 所有模组样式），
自己维护一套随机池，在切歌时调用 `setMode()` 换一种。

## 功能

- 池里可选任意样式：内建 17 种，加上你安装的所有歌词动画模组样式（`mod:` 前缀的都会列出来）。
- 切歌自动换，避免连着重复；池内同时有内建与模组样式时，每 3 次至少切一次模组样式，否则 17/19 的概率下
  模组样式几乎看不见。
- 播放页右侧有「随机池＋」标签：开关、全选 / 仅内建 / 仅模组 / 清空、逐项勾选、重抽一次、重新读取清单。
- 命令面板：`random-pool-reroll`（重抽一次）、`random-pool-toggle`（开 / 关接管）。
- 「全选」存的是「跟随清单」，之后新装的样式会自动并入，不用重新点全选。
- 新装模组需重启 Folia 才会被加载；之后打开面板会自动重读，或点「重新读取」。

## 使用

1. 设置 → 模组 → 打开「模组系统」，在模组面板里启用「随机池＋」并确认权限。
2. 播放页右侧面板 →「随机池＋」→ 点「全选」（19 项：17 内建 + 已装的模组样式）。
3. 想验证模组样式确实生效：点「仅模组」，下一首必定落在模组样式里。

## 与宿主自带随机的关系

宿主那一页（设置 → 歌词动画 → 随机池）改不了，也不含模组样式。两套随机同时开会抢同一个 `setMode`，
建议把宿主的「每首歌随机歌词动画」关掉，只留本模组。

## 权限

- `visualizer.mode`：只用于 `folium.visualizer.setMode(id)` 切换歌词动画模式，等价于用户在播放页手动切换。
  不读写文件、不联网、不碰账号。

不需要其它权限；`folium.visualizer.listModes()` 与 `getMode()` 读取不需要权限。

## 兼容

- Folium 1（`folium: 1`）
- Folia `>=0.7.22 <0.8.0`（依赖 1.8 起的 `folium.visualizer`）
- 纯 client 模组，无 main 入口、无第三方库、无构建步骤
